# Momo 记账（AI 记账本）

一款**零操作负担**的安卓 AI 记账 App：自动读取微信/支付宝/银行渠道的支付信息并自动入账分类，配合目标储蓄、预算管理与 AI 周度评价。奶油色系 + 小熊陪伴感 UI。

> 数据全部存在本机 SQLite，不联网、不上传。

## 功能特性

| 模块 | 说明 |
|---|---|
| 自动导入·通知监听 | 监听微信支付、支付宝消息盒子的支付通知，解析金额/商户/收支方向自动入账 |
| 自动导入·银行短信 | 接收银行扣款短信（含"余额"时自动同步银行卡余额）；带**近 24 小时收件箱扫描兜底** |
| 自动导入·银行 App 动账 | 监听招行/工行等银行 App 的动账推送通知 |
| 自动导入·微信零钱 | 无障碍服务读取微信"微信支付"会话列表预览（"已支付¥X"）+ 一键自动同步（自动打开微信、自动查找对话、自动读取、自动返回） |
| 手动记账 | 「＋」快速表单：金额/商户/分类/扣款账户/日期 |
| 分类体系 | 饮食/交通/服装/美妆/娱乐/医疗/住房/日常，本地关键词引擎自动分类，可点按纠正 |
| 首页 | 月度收入支出、年月选择器、总资产（三账户汇总/可隐藏）、消费明细流（按日分组） |
| 目标体系 | 存钱目标/购物目标进度条 + 攻略视频链接 + 存入记录 |
| 预算 | 月预算 → 每日可消费环形图、日均/本周/上月对比 |
| AI 周度评价 | 本地模板引擎：本周 vs 上周对比，强关联储蓄目标，星级评分 |
| 其他 | 节假日自动提示、自定义虚化背景、明细编辑/删除、诊断日志页 |

## 自动导入渠道矩阵

| 渠道 | 实现方式 | 系统要求 |
|---|---|---|
| 支付宝 | 通知监听（系统交易提醒） | 通知使用权 |
| 微信（绑卡支付） | 银行短信 / 银行 App 动账通知 | 通知使用权 / 短信权限 |
| 银行卡 | 银行短信（广播 + 收件箱扫描） | 短信权限 |
| 银行 App | 动账推送通知（含 mms） | 通知使用权 |
| 微信零钱 | 无障碍服务读屏（凭证卡片/列表预览） | 无障碍服务 |

> 已知限制：iOS 无法做通知/短信自动导入；微信扫码支付不产生系统通知，零钱捕获依赖无障碍读屏。

## 构建

需要 JDK 17、Android SDK（API 34 + build-tools 34）与 Gradle 8.7。

```bash
# 一键脚本（自动下载工具链并构建，含图标解码）
bash build-apk.sh <版本号>
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

图标以 base64 文本形式存于 `icons/`（避免二进制文件进 git），构建脚本自动解码为各密度 PNG。

## 使用准备

1. 安装 APK（允许未知来源）
2. 首页横幅 → 开启**通知使用权**（微信/支付宝自动入账）
3. 「我的」→ 开启**短信权限**（银行短信）与**无障碍服务**（微信零钱）
4. 小米/MIUI：建议开启**自启动**、**省电策略无限制**、**后台弹出界面**，否则通知监听与自动返回会被系统拦截

## 技术要点

- 原生 Java 外壳 + WebView UI（`app/src/main/assets/www/index.html`），零三方依赖，极小体积（~120KB）
- SQLite 本地持久化，余额随入账自动联动，跨渠道 2 分钟同金额去重
- 解析器 `Parser.java`：双语序金额提取、营销短信过滤（退订/拒收/券类特征）、商户提取、离线关键词分类
- `BillListenerService`：通知监听（含 android.textLines 多行字段、银行 App 通用识别）
- `SmsReceiver` + 收件箱主动扫描（content://sms/inbox）
- `WeChatA11yService`：无障碍读屏 + 自动导航状态机（找对话/滚动/读取/返回）

## 隐私

支付通知与短信仅在本机解析，结构化账单保存在本机数据库，无任何网络请求。
